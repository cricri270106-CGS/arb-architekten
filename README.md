# arb Architekten – Gestaltungsvorschlag

Neuer Webauftritt als Vorschlag für die arb Architekten AG, Bern.
Inhalte und Bilder stammen von [arb.ch](https://arb.ch). Gestaltung angelehnt an die CLERA-Website, ruhiger und auf den Auftritt von arb abgestimmt.

Statische Seite (HTML/CSS/JS, keine Build-Schritte), gehostet über GitHub Pages.

- `index.html` – Struktur und Texte
- `styles.css` – Gestaltung (Hell-/Dunkelmodus)
- `app.js` – Portfolio-Filter, Projektansicht, Team, Animationen
- `projects.js` – 71 Projekte aus dem Portfolio von arb.ch
